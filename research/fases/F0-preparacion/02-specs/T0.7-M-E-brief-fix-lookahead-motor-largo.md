## The defect, measured and localized

`scripts/analysis/realtick_bt/backtest.py:130-139`, verbatim:

```python
def first_at(self, t_sec: float):
    """First tick with t >= t_sec (spills across month files as needed)."""
    for ym in self._candidates(t_sec):     # chronological -> first hit is the earliest
        ta, bid, ask = self._load(ym)
        if not len(ta):
            continue
        i = int(np.searchsorted(ta, t_sec, "left"))
        if i < len(ta):
            return float(ta[i]), float(bid[i]), float(ask[i])
    return None
```

This is a **forward search with no time bound**. `_candidates(t_sec)` (`backtest.py:113-128`)
returns three months `[month-1, month, month+1]`, so the only limit is ±1 month of *file*, **not a
distance in time**. When the requested instant falls inside a market gap — daily close, weekend,
broker maintenance cut, feed outage — the function **does not return `None`**: it returns the first
tick *after* the gap and hands it over as if it were the price prevailing at the requested instant.

**This is look-ahead**, the same family as the same-bar fills that `research/NEGATIVOS.md` records
as `🔒 resuelto, no re-abrible` after they cost −121 % of net.

### The two consumption sites, and why each matters

**(1) `backtest.py:353`, inside `resolve()` — the ENTRY.** Actual block:

```python
    for bi in range(lo, max(lo + 1, hi)):
        tc = float(bar_times[bi]) + BAR_SEC
        if tc >= pos["t_out"] + BAR_SEC:            # would open at/after its own exit
            break
        e = ticks.first_at(tc)
        if e is None:
            continue
        _, ebid, eask = e
        sp = eask - ebid
        if abs(sp - 0.5) <= 0.05:
            entry = (tc, ebid, eask, round(sp, 3)); delay_bars = bi - lo; break
```

Two consequences, both serious:
- **The spread gate is decided with a future spread** (`sp` comes from the returned tick).
- **The entry is stamped with time `tc` and future prices** — grid time, another moment's price. In
  the replica, this exact pattern produced entries off by up to **2.04 days** (ledger row
  `F0-A6-BORDE-0001` in `research/LEDGER.jsonl`).

**(2) `backtest.py:383` — the bar-close EXIT** (when the level was not crossed):


Same defect: the exit price can come from hours later.

## What to build (closed spec)

### E.1 · The bound in `Ticks.first_at`

Add to `scripts/analysis/realtick_bt/backtest.py` a **maximum tolerance** between the requested
instant `t_sec` and the timestamp of the returned tick. If `t_tick - t_sec > tolerance`, `first_at`
returns **`None`** — exactly as it already does when there is no later tick at all.

Returning `None` is the correct choice and is not negotiable: **both consumption sites already
handle `None`** (`backtest.py:354` does `continue`, `backtest.py:384` does `return None`). That is
why this correction **requires no change to `resolve()` logic**: only to the source.

- The tolerance lives as an instance attribute, set in `Ticks.__init__` as a **keyword argument with
  a default value**.
  🔴 **It MUST be keyword-with-default:** `AvaTicks.__init__`
  (`scripts/research/backtest_largo_ava.py`) calls `super().__init__()` **with no arguments**. A
  positional or defaultless parameter breaks the AVA long engine.
- **Default value: `60.0` seconds.** Justification on record, not eyeballed: it is an order of
  magnitude above the p90 of healthy calls (3.268 s) and below every one of the 945 contaminated
  ones (all > 60 s by construction of the measurement).
- **The default is ON.** Do not implement this as opt-in. A fix you have to remember to enable
  silently reintroduces the defect the first time someone forgets, and that is exactly what charter
  §A.13 calls silent degradation.

### E.2 · The fix reaches the AVA long engine for free — verify it, do not assume it

`AvaTicks` (`scripts/research/backtest_largo_ava.py`) **subclasses `bt.Ticks` and overrides only
`_load`**; it inherits `first_at`, `range` and `_candidates` byte-identically. Therefore fixing
`bt.Ticks.first_at` corrects **both engines with a single change**.

🔴 **Do not duplicate the fix inside `AvaTicks`.** The only thing you might need there is making the
tolerance configurable from its `__init__`; if the default suffices, do not touch that file.
**Verify by reading** that inheritance is as described here, and report it.
