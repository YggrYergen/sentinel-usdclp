# `news_calendar.csv` — B2 blackout calendar (data, not a knob)

This file is DATA, not configuration: it is a committed, static list of `utc_datetime,label`
rows consumed by `sentinel_engine/live/news_calendar.py::load_windows()` to build the B2
news-blackout gate's blocked windows (`sentinel_engine/live/risk_gates.py`). The gate blocks
opens inside a **±30 minute** window around each row's timestamp; that window is a fixed
convention from the spec (§4.3), not a value chosen or swept from a backtest. All timestamps
are **real UTC** (the same clock as `datetime.now(timezone.utc)`), never MT5 broker server time.
The rows currently present were generated by a fixed rule — US Non-Farm Payrolls, first Friday
of each month, 12:30 UTC (08:30 America/New_York) — because no user-supplied calendar export
(`data/live/news_calendar_source.md`) existed at the time this file was built; if that source
file is later dropped in, its events should be transcribed here (converted to real UTC) in
addition to or instead of the rule-generated rows. **Missing events in this file mean B2
under-protects (a real news event with no row will not be blocked) — it never over-protects.**
The user should extend this file with CPI, FOMC and PPI release dates, which are irregular
(committee-scheduled, not date-rule-driven) and cannot be rule-generated the way NFP can.
